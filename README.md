# AI Court — сопровождение открытого урока

Интерактивный сайт для урока **«Человек против ИИ: кому доверить решение?»**.

Сайт рассчитан на работу параллельно с презентацией:
- студенты заходят с телефонов/ноутбуков;
- объединяются в физические группы по 3–4 человека;
- роли закрепляются на весь урок;
- преподаватель открывает задания из отдельной **Панели судьи**;
- ответы и статистика обновляются примерно раз в 1–1.5 секунды;
- можно сбросить один этап, весь прогресс или полностью заседание;
- результаты можно выгрузить в CSV.

## Роли внутри группы

Для группы из 3 человек:
1. Обвинитель
2. Защитник
3. Эксперт — он же фиксирует итог группы

Для группы из 4 человек:
1. Обвинитель
2. Защитник
3. Эксперт
4. Секретарь — фиксирует итог группы

Роль назначается при первом входе и **не меняется**.

## Быстрый запуск без базы данных

### Самый простой способ на Windows

1. Полностью распакуйте архив.
2. Запустите `START_DEMO.bat`.
3. Откроются две вкладки: студент и Панель судьи.
4. Код демо-заседания: `AI-01`.
5. В демо-режиме токен судьи можно оставить пустым.

`START_DEMO.bat` запускает обычный локальный web-server через установленный Python. Это важно: так вкладки студента и преподавателя используют одно хранилище и видят изменения друг друга.

Если просто открыть `index.html` и `teacher.html` двойным кликом, страницы теперь загрузятся, но браузеры по-разному изолируют `file://`-хранилище, поэтому связь между двумя страницами не гарантируется. Для проверки взаимодействия используйте `START_DEMO.bat`.

Supabase для демо **не нужен**. Ответы разных физических устройств в демо-режиме не синхронизируются — для реального урока подключите Supabase.

## Полноценный режим для урока — Supabase

### 1. Создайте проект Supabase

Откройте Supabase и создайте новый проект.

### 2. Включите Anonymous Sign-Ins

Authentication → Providers → Anonymous → Enable.

Регистрация студентам не нужна; каждому браузеру создаётся временный анонимный пользователь.

### 3. Выполните SQL

Откройте SQL Editor и выполните весь файл:

`supabase.sql`

Внизу файла есть начальная сессия:
- код занятия: `AI-01`
- токен преподавателя: `COURT-2026-CHANGE-ME`

**Обязательно замените токен на свой** перед публикацией.

### 4. Заполните config.js

В Supabase: Project Settings → API.

Вставьте Project URL и anon/publishable key:

```js
window.AICourtConfig = {
  supabaseUrl: "https://YOUR-PROJECT.supabase.co",
  supabaseAnonKey: "YOUR-ANON-OR-PUBLISHABLE-KEY",
  defaultSessionCode: "AI-01",
  demoModeWhenUnconfigured: true
};
```

Anon/publishable key можно использовать на клиенте. Доступ к данным ограничивается RLS и RPC-функциями из `supabase.sql`.

## Настройка групп

До входа студентов откройте `teacher.html`.

Введите:
- код заседания `AI-01`;
- ваш teacher token.

В блоке «Группы» можно выбрать:
- количество групп;
- максимум 3 или 4 человека в группе.

Студент при входе может выбрать номер своей физической группы. Если не выбирает — сайт положит его в наименее заполненную группу.

Это удобно, если вы заранее рассадили студентов по столам.

## Как вести урок

1. На проекторе идёт PowerPoint.
2. На вашем ноутбуке во второй вкладке открыт `teacher.html`.
3. Студенты держат открытым `index.html`.
4. Когда доходите до интерактивного слайда, в Панели судьи нажимаете нужный этап.
5. У студентов он появляется автоматически.
6. В панели вы видите статистику и короткие ответы.

## Сброс

Есть три уровня:

- **Сбросить текущий этап** — удаляет ответы только текущего задания.
- **Начать урок заново, сохранив группы** — удаляет все ответы, но сохраняет участников и закреплённые роли.
- **Полный сброс заседания** — удаляет участников, группы, роли и все ответы. Требует вручную ввести `СБРОСИТЬ`.

## GitHub Pages

Этот проект полностью статический: HTML/CSS/JS + Supabase как внешний backend.

1. Создайте GitHub-репозиторий.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/ (root)`.
6. Сохраните.

Файл `.nojekyll` уже добавлен.

## Файлы

- `index.html` — интерфейс студента
- `teacher.html` — Панель судьи
- `styles.css` — дизайн и адаптив
- `student.js` — логика студента
- `teacher.js` — статистика и управление
- `core.js` — общие функции
- `activities.js` — задания урока
- `config.js` — подключение Supabase
- `supabase.sql` — база, роли, безопасность и RPC
- `assets/` — изображения, GIF и favicon

## Важное перед открытым уроком

Проверьте заранее с 2–3 телефонами:
- вход по коду;
- распределение ролей;
- появление нового задания;
- запись индивидуального ответа;
- групповой вердикт;
- сброс текущего этапа;
- полный сброс;
- экспорт CSV.
